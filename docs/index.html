01Quelle in der Installation hinterlegen
ORBIT_CATALOG_URL=…
Die Adresse gehört in die .env deiner Orbit-Installation. Der Docker-Dienst braucht ausgehenden HTTPS-Zugriff auf diese Quelle.
02Container-Konfiguration übernehmen
cd /orbit-central
docker compose up -d --force-recreate
Dabei startet ausschließlich der Orbit-Dienst neu. Beim Start prüft er den Katalog und lädt fehlende Dateien im Hintergrund. Den Status findest du im Marketplace.
